Política de privacidad

Última actualización: 4 de septiembre de 2026

FabricadeReels es una herramienta local y de uso personal. No se ofrece como servicio a terceros, no permite crear cuentas y no recopila datos para publicidad, elaboración de perfiles ni venta.

Información que procesa

Para subir un video, la herramienta procesa únicamente:

  • el archivo de video creado localmente;
  • su título, descripción, etiquetas y configuración de privacidad;
  • un token OAuth emitido por Google para la cuenta autorizada.

FabricadeReels no solicita ni conoce la contraseña de Google. El inicio de sesión y el consentimiento ocurren directamente en páginas de Google.

Uso de la información

La información se usa exclusivamente para subir a YouTube los videos que el propietario produce y para evitar subidas duplicadas. La aplicación no lee mensajes, contactos ni archivos ajenos a este proceso; tampoco elimina videos ni modifica contenido existente mediante la API.

Almacenamiento y conservación

El token OAuth y el registro de cada subida se guardan únicamente en el equipo donde se ejecuta la herramienta. Se conservan mientras la automatización permanezca activa o hasta que el propietario los elimine. No existe una base de datos externa operada por FabricadeReels.

Transferencia y divulgación

El video y sus metadatos se transmiten a Google exclusivamente a través de la API de YouTube para completar la subida autorizada. FabricadeReels no vende, alquila ni comparte los datos con otras empresas o personas.

Servicios de Google y uso limitado

El uso de la información recibida de las APIs de Google se adhiere a la Política de Datos de Usuario de los Servicios de API de Google, incluidos sus requisitos de Uso Limitado.

Revocación y eliminación

El propietario puede revocar el acceso desde Conexiones de la cuenta de Google. También puede borrar el archivo local control/youtube_token.json para eliminar la credencial guardada. Los videos ya subidos se administran o eliminan directamente desde YouTube Studio.

Seguridad

Las credenciales se excluyen del control de versiones. La herramienta solicita el alcance OAuth mínimo necesario para subir videos y utiliza HTTPS mediante las bibliotecas oficiales de Google.

Contacto

Las consultas sobre esta política pueden enviarse mediante el repositorio público de FabricadeReels en GitHub.
